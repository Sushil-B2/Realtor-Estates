Add your Neon API key

This writes NEON_API_KEY into .secrets/neon-api-key on the server — mode 0600, git-ignored, and not loaded by the app process. Nothing you paste is ever echoed, logged, or stored in audit records — only a SHA-256 fingerprint is recorded.

Viewing raw file? If clicking buttons below does nothing, you opened web/keysetup.html in the static File Viewer (which has no server connection). Switch to the Realtor Estates App Live Preview panel instead, or sign in on the main preview and open Security → Neon Operator Credentials.

Step 1 of 2. Only an owner session may write a credential; a viewer or an anonymous request is refused by the API.

Step 2 of 2. Get the API key from console.neon.tech → Account settings → API keys → Create new API key. Saving replaces any existing value atomically with mode 0600.
